`React` `Three.js` `R3F` `OpenF1` `Zustand` `Vite`

Interactive circuit explorer with 3D visualization and real telemetry comparison. Pulls live qualifying data from OpenF1, aligns it to track geometry via rotation-search projection, and renders speed-colored ribbons + variable-speed car dots in WebGL. Zero backend — all client-side.

[`Live Demo ↗`](https://f1-track-metrics-lab.vercel.app) [`Source ↗`](https://github.com/yashyegare/F1TrackMetricsLab)

</td>

> **Why two projects, not one?** The prediction app needs server-side ML inference and auth — the Track Metrics Lab doesn't. Merging them would add a failure domain and deployment coupling for no functional benefit. The visualization loads in <1s on mobile *because* it has zero backend dependency. Each project demonstrates a different architectural instinct: server-side computation vs. client-side visualization.
